# Specs and reports

Each file is the brief given to one agent of a development wave, followed by that agent's
**Report** (what was built, how it was verified, third-party components, packaging notes and
"Requests to the coordinator"). They are kept as the project's history and as the list of open
requests; the current state of the code is described in `docs/ARCHITECTURE.md` and `README.md`.

| file | scope |
|---|---|
| A-pdf.md | engine-pdf and the PDF tools |
| B-image.md | engine-ml and the image tools |
| C-media.md | engine-media and the video/audio tools |
| D-app.md | the app shell |
| E-create-files.md | create and files tools, MCP server |
| F-studios.md | studios, workspaces, system integration |
| G-release.md | packaging, signing, updates |
| H-site-video.md | presentation page, X images, promo video |
